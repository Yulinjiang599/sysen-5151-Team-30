## 关键数值链路

临时任务 60 分钟时：缺口 300m → 工作量增至 120 分钟：缺口 360m → 添加周日两小时：缺口 240m。刷新、关闭重开后结果保留。

## 发现与限制

- Calendar short blocks truncate long names; Agenda is a readable alternative.
- UI says Private workspace loaded although there is no authenticated access; retain as a known wording issue, not privacy acceptance.
- Local static server requested favicon.ico and received 404; application HTML and all three scripts loaded successfully.
- One browser environment; not the two named/versioned browser acceptance set.
- Single refresh and close/reopen sequence, not five independent recovery cases.
- Native deadline editing, task completion/deletion, What-if Apply, import/export file dialogs and timer were not exercised.
- No performance acceptance timing or student usability pilot.
- Profile selection is not authentication or authorization.
- No remote CI run for this Desktop package.

## 下一步

完整浏览器验收仍需要补足上面未测路径；若课程要求当前版本远端 CI 成功，需用户授权上传并由 GitHub Actions 实际运行。模型输入边界、CR-14 和计划确认缺口仍需团队决定，不能通过录屏措辞掩盖。
